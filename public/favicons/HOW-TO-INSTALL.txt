MSL Biotech favicon package
===========================

1. Upload every file in this folder to your website root (same level as index.html).
2. Paste the tags below inside the <head> of every page:

<!-- Favicons: place all files in your site root -->
<link rel="icon" href="/favicon.ico" sizes="any">
<link rel="icon" type="image/png" sizes="32x32" href="/favicon-32x32.png">
<link rel="icon" type="image/png" sizes="16x16" href="/favicon-16x16.png">
<link rel="apple-touch-icon" sizes="180x180" href="/apple-touch-icon.png">
<link rel="manifest" href="/site.webmanifest">
<meta name="theme-color" content="#184EA4">
